# ტერმინოლოგიური ლექსიკონი (`ka.json`)

ერთ ცნებას **ერთი** ქართული სიტყვა აქვს. მიზეზი ტასკ GAP-15-შია: ერთი და იგივე
ველი სამ გვერდზე სამი სახელით ერქვა („საყურებელი ლინკი" · „ყურების ბმული"),
ხოლო „ჩამოწერა" ლოკალურ ასლზე და „ჩამოტვირთვა" გალერეაზე ერთსა და იმავეს
აღნიშნავდა — მომხმარებელი ვერ ხვდებოდა, ერთი საქმეა თუ ორი.

⚠️ **ეს ლექსიკონი ინტერფეისის ტექსტს ეხება, ე.ი. `ka.json`-ს.** კოდის
კომენტარები (რომლებიც ამ რეპოში ასევე ქართულადაა) არ მოწმდება — ისინი
დეველოპერს ელაპარაკებიან და პროდუქტის ლექსიკას არ ქმნიან.

## ცხრილი

| ცნება (en) | სწორია | აკრძალულია | შენიშვნა |
|---|---|---|---|
| link | **ბმული** | ლინკი | `ge_url` ყველგან „საყურებელი ბმული"-ა |
| sync | **სინქრონიზაცია** | სინქრონი | ზმნა — „სინქრონიზდება…"; ზედსართავი — „სინქრონიზებული" |
| download | **ჩამოტვირთვა** | ჩამოწერა, ჩამოიწერა | ერთი სიტყვა ვიდეოს ლოკალურ ასლსა და გალერეის ფოტოზე |
| thumbnail | **ესკიზი** | თამბნეილი | შენი არჩევანი 2026-09-18; „სურათი" ზოგადია და დიდ ფოტოსაც ნიშნავს |
| API key | **გასაღები** | კლავიში | „კლავიში" კლავიატურის ღილაკია |
| nickname | **მეტსახელი** | ნიკნეიმი | ჩატის `§10.11` |
| franchise | **ფრანჩაიზი** | ფრენჩაიზი | BUG-18-მა გაასწორა |

## სამი „ნოუთი" — სამი სხვადასხვა რამ

ერთი ინგლისური სიტყვა (`note`) ამ აპში სამ სხვადასხვა ობიექტს ნიშნავს, ამიტომ
ქართულშიც სამი სიტყვაა და **მათი აღრევა შეცდომაა**:

| რა არის | ქართულად | სად |
|---|---|---|
| `note` მოდულის ჩანაწერი | **ჩანაწერი / ჩანაწერები** | მოდულის სახელი ბაზაშია (`modules.name_ka`), არა i18n-ში |
| ჩანაწერზე მიმაგრებული ნოუთი (`*_notes`) | **ჩანიშვნა** | `videos.tabNotes`, `books.notesTitle`, `search.field.note`, `games.dlcNote` |
| ადმინის/ოპერაციული კომენტარი | **შენიშვნა** | `requests.noteLabel` (განხილვის კომენტარი), `backups.note` (ასლის კომენტარი) |

⚠️ „ჩანაწერი" ამავე დროს ზოგადი სიტყვაა ბიბლიოთეკის ნებისმიერ ერთეულზე
(„{{count}} ჩანაწერი წაიშლება"). ეს განზრახ არაა შეცვლილი: მოდულის სახელს
ბაზა ფლობს და მისი გადარქმევა ამ ფაილიდან შეუძლებელია.

## ლათინური სიტყვა ქართულ წინადადებაში

ქართულ ტექსტში ინგლისური სიტყვა მაშინ რჩება, როცა ის **საკუთარი სახელია**
(TMDB, YouTube, Gemini), **ბრძანება/ფაილია** (`php artisan …`, `php.ini`,
`yt-dlp`) ან **პროვაიდერის მენიუს სიტყვაა** („Create API key"). ყველა
დანარჩენს ქართული შესატყვისი აქვს:

| იყო | არის |
|---|---|
| default-ად ჩართული | **ნაგულისხმევად** ჩართული |
| private დისკზე | **პირად** დისკზე |
| abuse-ის შემთხვევაში | **ბოროტად გამოყენების** შემთხვევაში |
| ერთი credit-ია | ერთი **კრედიტია** |
| ვებძებნის engine | ვებძებნის **საძიებო სისტემა** |
| ბაზა backup-იდან აღდგა | ბაზა **ასლიდან** აღდგა |

⚠️ **განმასხვავებელი რეგისტრია და არა ლექსიკონი.** ბრენდი ყოველთვის დიდი
ასოთია და ქართული ბრუნვაც თავისუფლად მოსდევს (`TMDB-ის`); დეფექტი კი
ყოველთვის პატარა ასოებით დაწერილი ჩვეულებრივი სიტყვაა. `audit.py`-ის მე-10
შემოწმება სწორედ ამ ზღვარზე დგას — 236 ლათინური ტოკენიდან მას 38 გადის,
დანარჩენი კი `LATIN_OK`-შია, თითო მიზეზით.

⚠️ მეექვსე („backup-იდან") **თვითონ შემოწმებამ იპოვა** და არა აუდიტმა:
`backups.*` მთელ სექციაში „ასლი"-ა, ე.ი. იმავე ცნებას მეორე სახელი ერქვა.

## მიმართვა — შენობითზე

აპი მთლიანად **შენობითზეა** („აირჩიე", „დააჭირე", „ჩასვი"). ეს სტილის ერთი
გადაწყვეტილებაა და არა თითო ტექსტის: 2690 გასაღებიდან სამი თქვენობითში იყო
(`search.hint`, `search.emptyHint`, `fields.unlockWarning*`) და ისინი გვერდზე
სხვა ხმით ლაპარაკობდნენ.

⚠️ **ერთი გამონაკლისია და ის თქვენობითი არ არის**: `matches.sharedTotal`
(„თქვენ ორივეს გაქვთ…") **ორ ადამიანს** მიმართავს — მრავლობითი იქ იმიტომაა,
რომ ორნი არიან, და არა ზრდილობის გამო.

⚠️ **`-ეთ` დაბოლოება თავისთავად ნიშანი არაა.** „ასეთ"/„გარეთ" ზმნები არაა,
ხოლო „ვნახეთ"/„წავიკითხეთ"/„გავიარეთ"/„მივყვეთ" **პირველი პირის მრავლობითია**
(„ორივემ ვნახეთ") — სწორი ფორმაა. `audit.py`-ის მე-8 შემოწმება სწორედ ამიტომ
ინახავს სიტყვების allow-სიას და არა გასაღებებისას.

## როგორ არის დაცული

`audit.py`-ის მე-7 შემოწმება (`python frontend/src/i18n/audit.py`) აკრძალულ
სიტყვას `ka.json`-ში პოულობს და აუდიტს წითლად ამთავრებს. ახალი წყვილის
დამატება — ერთი ხაზი `BANNED`-ში, აქ კი ერთი მწკრივი.

⚠️ „სინქრონი" ავტომატურად **არ** მოწმდება: ის სწორი „სინქრონიზაციის"
ქვესტრიქონია, ე.ი. შემოწმება ყოველ სწორ ხმარებაზე იყვირებდა. დანარჩენ ექვს
ცნებას `audit.py` იცავს.

⚠️ მე-8 შემოწმება (GAP-18) იმავე გაშვებაში თქვენობით ფორმებს ეძებს — იხ.
„მიმართვა — შენობითზე".

⚠️ მე-10 შემოწმება (GAP-20) ლათინურ სიტყვას ეძებს — იხ. „ლათინური სიტყვა
ქართულ წინადადებაში".
